# Pemetaan Source-to-Target (STTM) Domain Purchasing

## 1. Tabel Dimensi: DimVendor
- **Target Table:** `DimVendor`
- **Source Table(s):** `Purchasing.Vendor`, `Person.BusinessEntityAddress`, `Person.Address`, `Person.StateProvince`

| Target Column | Target Data Type | Primary / Foreign Key | Source Table(s) | Source Column / Logic Transformation | Transformation / Business Rules |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `VendorSK` | INT (AUTO_INCREMENT) | Primary Key (Surrogate Key) | N/A | Generated by ETL | Key pengganti (surrogate key) unik untuk DW. |
| `BusinessEntityID` | INT | Natural Key | `Purchasing.Vendor` | `BusinessEntityID` | ID Vendor asli dari OLTP. |
| `AccountNumber` | VARCHAR(15) | - | `Purchasing.Vendor` | `AccountNumber` | Nomor rekening/akun unik vendor. |
| `VendorName` | VARCHAR(50) | - | `Purchasing.Vendor` | `Name` | Nama resmi perusahaan/pemasok vendor. |
| `CreditRating` | TINYINT | - | `Purchasing.Vendor` | `CreditRating` | Rating kredit vendor (1 s.d. 5). |
| `PreferredVendorStatus` | BOOLEAN | - | `Purchasing.Vendor` | `PreferredVendorStatus` | Penanda vendor prioritas (`1` = Ya, `0` = Tidak). |
| `ActiveFlag` | BOOLEAN | - | `Purchasing.Vendor` | `ActiveFlag` | Status aktif vendor (`1` = Aktif, `0` = Inaktif). |

## 4. Tabel Dimensi: dim_tanggal
- **Target Table:** `dim_tanggal`
- **Source Table(s):** Generated / Derived (menggunakan CTE Rekursif dari `2010-01-01` s.d. `2015-12-31`)

| Target Column | Target Data Type | Primary / Foreign Key | Source Table(s) | Source Column / Logic Transformation | Transformation / Business Rules |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `tanggal_key` | INT | Primary Key | N/A | `CAST(DATE_FORMAT(d, '%Y%m%d') AS UNSIGNED)` | Format integer `YYYYMMDD`. Nilai `-1` untuk data tanggal tidak diketahui. |
| `tanggal` | DATE | Unique | N/A | `DATE(d)` | Tanggal lengkap format `YYYY-MM-DD`. |
| `tahun` | INT | - | N/A | `YEAR(d)` | Ekstrak tahun empat digit (contoh: 2013). |
| `semester` | INT | - | N/A | `IF(MONTH(d) <= 6, 1, 2)` | Semester 1 (Jan-Jun) atau 2 (Jul-Des). |
| `kuartal` | INT | - | N/A | `QUARTER(d)` | Triwulan/Kuartal (1 s.d. 4). |
| `bulan` | INT | - | N/A | `MONTH(d)` | Bulan dalam angka (1 s.d. 12). |
| `nama_bulan` | VARCHAR(15) | - | N/A | `ELT(MONTH(d), 'Januari', ..., 'Desember')` | Nama bulan dalam Bahasa Indonesia. |
| `minggu_dalam_tahun` | INT | - | N/A | `WEEK(d, 3)` | Minggu ke-n dalam tahun berdasarkan standar ISO 8601 (1 s.d. 53). |
| `tanggal_dalam_bulan` | INT | - | N/A | `DAY(d)` | Tanggal/hari dalam bulan (1 s.d. 31). |
| `hari_dalam_minggu` | INT | - | N/A | `WEEKDAY(d) + 1` | Hari ke-n dalam seminggu (Senin = 1 s.d. Minggu = 7). |
| `nama_hari` | VARCHAR(15) | - | N/A | `ELT(WEEKDAY(d) + 1, 'Senin', ..., 'Minggu')` | Nama hari dalam Bahasa Indonesia. |
| `is_akhir_pekan` | BOOLEAN | - | N/A | `WEEKDAY(d) >= 5` | Penanda akhir pekan (`1` untuk Sabtu dan Minggu, `0` untuk hari kerja). |

## 5. Tabel Fakta: FactPurchasing
- **Target Table:** `FactPurchasing`
- **Source Table(s):** `Purchasing.PurchaseOrderHeader`, `Purchasing.PurchaseOrderDetail`, `DimVendor`, `DimProduct`, `DimEmployee`, `dim_tanggal`

| Target Column | Target Data Type | Primary / Foreign Key | Source Table(s) | Source Column / Logic Transformation | Transformation / Business Rules |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `PurchaseFactID` | BIGINT (AUTO_INCREMENT) | Primary Key | N/A | Generated by ETL | Primary Key unik tabel fakta pembelian. |
| `PurchaseOrderID` | INT | Degenerate Dimension | `Purchasing.PurchaseOrderHeader` | `PurchaseOrderID` | Nomor pesanan pembelian dari OLTP. |
| `PurchaseOrderDetailID` | INT | Degenerate Dimension | `Purchasing.PurchaseOrderDetail` | `PurchaseOrderDetailID` | Detail rincian baris pesanan barang. |
| `VendorSK` | INT | Foreign Key | `DimVendor` | Lookup to `DimVendor.VendorSK` via `PurchaseOrderHeader.VendorID = DimVendor.BusinessEntityID` | Surrogate key dari tabel dimensi vendor/pemasok. |
| `ProductSK` | INT | Foreign Key | `DimProduct` | Lookup to `DimProduct.ProductSK` via `PurchaseOrderDetail.ProductID = DimProduct.ProductID` | Surrogate key dari tabel dimensi produk. |
| `EmployeeSK` | INT | Foreign Key | `DimEmployee` | Lookup to `DimEmployee.EmployeeSK` via `PurchaseOrderHeader.EmployeeID = DimEmployee.BusinessEntityID` | Surrogate key dari tabel dimensi pegawai/buyer. |
| `OrderDateKey` | INT | Foreign Key | `dim_tanggal` | Lookup to `dim_tanggal.tanggal_key` via `COALESCE(DATE_FORMAT(PurchaseOrderHeader.OrderDate, '%Y%m%d'), -1)` | Merujuk tanggal pemesanan barang. |
| `ShipDateKey` | INT | Foreign Key | `dim_tanggal` | Lookup to `dim_tanggal.tanggal_key` via `COALESCE(DATE_FORMAT(PurchaseOrderHeader.ShipDate, '%Y%m%d'), -1)` | Merujuk tanggal pengiriman barang oleh vendor. |
| `OrderQty` | INT | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `OrderQty` | Kuantitas barang yang dipesan. |
| `ReceivedQty` | DECIMAL(8,2) | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `ReceivedQty` | Kuantitas fisik barang yang diterima di gudang. |
| `RejectedQty` | DECIMAL(8,2) | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `RejectedQty` | Kuantitas barang yang ditolak/cacat. |
| `UnitPrice` | DECIMAL(18,2) | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `UnitPrice` | Harga beli satuan barang dari vendor. |
| `LineTotal` | DECIMAL(18,2) | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `LineTotal` | Total harga per item line (`OrderQty * UnitPrice`). |
| `TaxAmt` | DECIMAL(18,2) | Metric / Measure | `Purchasing.PurchaseOrderHeader` | `TaxAmt * (LineTotal / SubTotal)` | Pajak pembelian dihitung proporsional per item line. |
| `Freight` | DECIMAL(18,2) | Metric / Measure | `Purchasing.PurchaseOrderHeader` | `Freight * (LineTotal / SubTotal)` | Biaya kirim pembelian dihitung proporsional per item line. |
