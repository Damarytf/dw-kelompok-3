# Pemetaan Source-to-Target (STTM)

## 1. Tabel Dimensi: DimCustomer
* **Target Table:** `DimCustomer`
* **Source Table(s):** `Sales.Customer`, `Person.Person`, `Sales.Store`, `Person.PersonPhone`, `Person.EmailAddress`

| Target Column | Target Data Type | Primary / Foreign Key | Source Table(s) | Source Column / Logic Transformation | Transformation / Business Rules |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `CustomerSK` | INT (AUTO_INCREMENT) | Primary Key (Surrogate Key) | N/A | Generated by ETL | Key pengganti (surrogate key) unik untuk DW. |
| `CustomerID` | INT | Natural Key | `Sales.Customer` | `CustomerID` | ID Pelanggan asli dari OLTP. |
| `CustomerName` | VARCHAR(100) | - | `Person.Person` / `Sales.Store` | `CONCAT(FirstName, ' ', LastName)` / `Store.Name` | Jika `PersonID` ada, gabungkan nama depan & belakang. Jika `StoreID` ada, ambil Nama Toko. |
| `CustomerType` | VARCHAR(20) | - | `Sales.Customer` | `CASE WHEN PersonID IS NOT NULL THEN 'Individual' ELSE 'Store' END` | Mengelompokkan tipe pelanggan (Individu / Toko). |
| `Phone` | VARCHAR(25) | - | `Person.PersonPhone` | `PhoneNumber` | Ambil nomor telepon utama pelanggan. |
| `Email` | VARCHAR(50) | - | `Person.EmailAddress` | `EmailAddress` | Ambil alamat email pelanggan. |

## 4. Tabel Dimensi: dim_tanggal
* **Target Table:** `dim_tanggal`
* **Source Table(s):** Generated / Derived (menggunakan CTE Rekursif dari `2010-01-01` s.d. `2015-12-31`)

| Target Column | Target Data Type | Primary / Foreign Key | Source Table(s) | Source Column / Logic Transformation | Transformation / Business Rules |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `tanggal_key` | INT | Primary Key | N/A | `CAST(DATE_FORMAT(d, '%Y%m%d') AS UNSIGNED)` | Format integer `YYYYMMDD`. Nilai `-1` untuk data tanggal tidak diketahui. |
| `tanggal` | DATE | Unique | N/A | `DATE(d)` | Tanggal lengkap format `YYYY-MM-DD`. |
| `tahun` | INT | - | N/A | `YEAR(d)` | Ekstrak tahun empat digit (contoh: 2013). |
| `semester` | INT | - | N/A | `IF(MONTH(d) <= 6, 1, 2)` | Semester 1 (Jan-Jun) atau 2 (Jul-Des). |
| `kuartal` | INT | - | N/A | `QUARTER(d)` | Triwulan/Kuartal (1 s.d. 4). |
| `bulan` | INT | - | N/A | `MONTH(d)` | Bulan dalam angka (1 s.d. 12). |
| `nama_bulan` | VARCHAR(15) | - | N/A | `ELT(MONTH(d), 'Januari', ..., 'Desember')` | Nama bulan dalam Bahasa Indonesia. |
| `minggu_dalam_tahun` | INT | - | N/A | `WEEK(d, 3)` | Minggu ke-n dalam tahun berdasarkan standar ISO 8601 (1 s.d. 53). |
| `tanggal_dalam_bulan` | INT | - | N/A | `DAY(d)` | Tanggal/hari dalam bulan (1 s.d. 31). |
| `hari_dalam_minggu` | INT | - | N/A | `WEEKDAY(d) + 1` | Hari ke-n dalam seminggu (Senin = 1 s.d. Minggu = 7). |
| `nama_hari` | VARCHAR(15) | - | N/A | `ELT(WEEKDAY(d) + 1, 'Senin', ..., 'Minggu')` | Nama hari dalam Bahasa Indonesia. |
| `is_akhir_pekan` | BOOLEAN | - | N/A | `WEEKDAY(d) >= 5` | Penanda akhir pekan (`1` untuk Sabtu dan Minggu, `0` untuk hari kerja). |

## 5. Tabel Fakta: FactSales
* **Target Table:** `FactSales`
* **Source Table(s):** `Sales.SalesOrderHeader`, `Sales.SalesOrderDetail`, `DimCustomer`, `DimProduct`, `DimTerritory`, `dim_tanggal`

| Target Column | Target Data Type | Primary / Foreign Key | Source Table(s) | Source Column / Logic Transformation | Transformation / Business Rules |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `SalesFactID` | BIGINT (AUTO_INCREMENT) | Primary Key | N/A | Generated by ETL | Primary Key unik tabel fakta. |
| `SalesOrderID` | INT | Degenerate Dimension | `Sales.SalesOrderHeader` | `SalesOrderID` | Nomor transaksi header dari OLTP. |
| `SalesOrderDetailID` | INT | Degenerate Dimension | `Sales.SalesOrderDetail` | `SalesOrderDetailID` | Detail rincian baris transaksi. |
| `CustomerSK` | INT | Foreign Key | `DimCustomer` | Lookup to `DimCustomer.CustomerSK` via `SalesOrderHeader.CustomerID = DimCustomer.CustomerID` | Surrogate key dari tabel dimensi pelanggan. |
| `ProductSK` | INT | Foreign Key | `DimProduct` | Lookup to `DimProduct.ProductSK` via `SalesOrderDetail.ProductID = DimProduct.ProductID` | Surrogate key dari tabel dimensi produk. |
| `TerritorySK` | INT | Foreign Key | `DimTerritory` | Lookup to `DimTerritory.TerritorySK` via `SalesOrderHeader.TerritoryID = DimTerritory.TerritoryID` | Surrogate key dari tabel dimensi wilayah. |
| `tanggal_key` | INT | Foreign Key | `dim_tanggal` | Lookup to `dim_tanggal.tanggal_key` via `COALESCE(DATE_FORMAT(SalesOrderHeader.OrderDate, '%Y%m%d'), -1)` | Merujuk ke `dim_tanggal.tanggal_key`. Gunakan `-1` jika tanggal kosong/NULL. |
| `OrderQty` | INT | Metric / Measure | `Sales.SalesOrderDetail` | `OrderQty` | Jumlah kuantitas barang yang dibeli. |
| `UnitPrice` | DECIMAL(18,2) | Metric / Measure | `Sales.SalesOrderDetail` | `UnitPrice` | Harga satuan barang. |
| `UnitPriceDiscount` | DECIMAL(18,2) | Metric / Measure | `Sales.SalesOrderDetail` | `UnitPriceDiscount` | Nilai diskon satuan. |
| `LineTotal` | DECIMAL(18,2) | Metric / Measure | `Sales.SalesOrderDetail` | `LineTotal` | Calculated: `(OrderQty * UnitPrice) * (1 - UnitPriceDiscount)`. |
| `TaxAmt` | DECIMAL(18,2) | Metric / Measure | `Sales.SalesOrderHeader` | `TaxAmt * (LineTotal / SubTotal)` | Biaya pajak dihitung proporsional per baris detail. |
| `Freight` | DECIMAL(18,2) | Metric / Measure | `Sales.SalesOrderHeader` | `Freight * (LineTotal / SubTotal)` | Biaya pengiriman dihitung proporsional per baris detail. |
