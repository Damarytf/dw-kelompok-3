## 2. Tabel Dimensi: dim_produk (SCD Tipe 2)
- **Target Table:** `dim_produk`
- **Source Table(s):** `Production.Product`, `Production.ProductSubcategory`, `Production.ProductCategory`, `Production.ProductCostHistory` (via `stg_product*`)

| Target Column | Target Data Type | Primary / Foreign Key | Source Table(s) | Source Column / Logic Transformation | Transformation / Business Rules |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `sk_produk` | INT (AUTO_INCREMENT) | Primary Key (Surrogate Key) | N/A | Generated by ETL | Surrogate key untuk tabel dimensi produk (`-1` Unknown, `0` Dummy Pentaho). |
| `produk_id` | INT | Natural Key | `Production.Product` | `ProductID` | ID Produk asli dari OLTP. |
| `nama_produk` | VARCHAR(150) | - | `Production.Product` | `Name` | Nama resmi produk. |
| `kode_produk` | VARCHAR(50) | - | `Production.Product` | `ProductNumber` | Kode/Nomor unik produk. |
| `warna` | VARCHAR(30) | - | `Production.Product` | `COALESCE(Color, 'Unknown')` | Warna produk; nilai `NULL` dibersihkan menjadi `'Unknown'`. |
| `subkategori` | VARCHAR(100) | - | `Production.ProductSubcategory` | `COALESCE(Name, 'Unknown')` | Nama sub-kategori produk (`LEFT JOIN` via `ProductSubcategoryID`). |
| `kategori` | VARCHAR(100) | - | `Production.ProductCategory` | `COALESCE(Name, 'Unknown')` | Nama kategori utama produk (`LEFT JOIN` via `ProductCategoryID`). |
| `biaya_standar` | DECIMAL(19,4) | - | `Production.ProductCostHistory` / `Product` | `COALESCE(pch.StandardCost, p.StandardCost)` | Biaya standar historis/terkini (dilacak perubahannya dengan SCD Tipe 2). |
| `harga_jual` | DECIMAL(19,4) | - | `Production.Product` | `ListPrice` | Harga jual resmi produk. |
| `versi` | INT | SCD Tipe 2 Metadata | N/A | Generated by ETL | Nomor versi SCD Tipe 2 (bertambah otomatis jika `biaya_standar` berubah). |
| `berlaku_mulai` | DATETIME | SCD Tipe 2 Metadata | `Production.ProductCostHistory` | `StartDate` / ETL Timestamp | Tanggal awal berlakunya versi biaya standar produk. |
| `berlaku_sampai` | DATETIME | SCD Tipe 2 Metadata | `Production.ProductCostHistory` | `COALESCE(EndDate, '9999-12-31 23:59:59')` | Tanggal berakhirnya versi biaya standar produk. |

## 7. Tabel Fakta: fact_purchasing (Star Schema V2)
- **Target Table:** `fact_purchasing`
- **Source Table(s):** `Purchasing.PurchaseOrderHeader`, `Purchasing.PurchaseOrderDetail`, `Person.BusinessEntityAddress`, serta 6 tabel dimensi (`dim_tanggal`, `dim_karyawan`, `dim_produk`, `dim_vendor`, `dim_geography`, `dim_ship_method`)

| Target Column | Target Data Type | Primary / Foreign Key | Source Table(s) | Source Column / Logic Transformation | Transformation / Business Rules |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `sk_purchasing` | INT (AUTO_INCREMENT) | Primary Key | N/A | Generated by ETL | Primary Key unik tabel fakta pembelian. |
| `po_id` | INT | Degenerate Dimension | `Purchasing.PurchaseOrderHeader` | `PurchaseOrderID` | Nomor pesanan pembelian dari OLTP. |
| `po_detail_id` | INT | Degenerate Dimension | `Purchasing.PurchaseOrderDetail` | `PurchaseOrderDetailID` | Detail rincian baris pesanan barang. |
| `sk_tanggal` | INT | Foreign Key | `dim_tanggal` | Lookup `dim_tanggal.tanggal_key` via `DATE_FORMAT(OrderDate, '%Y%m%d')` (default `-1`) | Merujuk tanggal pemesanan barang (`OrderDate`). |
| `sk_karyawan` | INT | Foreign Key | `dim_karyawan` | Lookup `dim_karyawan.sk_karyawan` via `EmployeeID = karyawan_id` (default `-1`) | Surrogate key dari tabel dimensi pegawai/buyer. |
| `sk_produk` | INT | Foreign Key | `dim_produk` | Dimension Lookup `dim_produk.sk_produk` via `ProductID = produk_id` (default `-1`) | Surrogate key SCD Tipe 2 dari tabel dimensi produk. |
| `sk_vendor` | INT | Foreign Key | `dim_vendor` | Lookup `dim_vendor.sk_vendor` via `VendorID = vendor_id` (default `-1`) | Surrogate key dari tabel dimensi vendor/pemasok. |
| `sk_geography` | INT | Foreign Key | `dim_geography` | Lookup `dim_geography.sk_geography` via `BusinessEntityAddress.AddressID = address_id` (default `-1`) | Surrogate key lokasi geografis alamat utama vendor. |
| `sk_ship_method` | INT | Foreign Key | `dim_ship_method` | Lookup `dim_ship_method.sk_ship_method` via `ShipMethodID = ship_method_id` (default `-1`) | Surrogate key metode pengiriman pesanan. |
| `qty_order` | INT | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `OrderQty` | Kuantitas barang yang dipesan (`CHECK qty_order > 0`). |
| `qty_diterima` | DECIMAL(8,2) | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `ReceivedQty` | Kuantitas fisik barang yang diterima di gudang. |
| `qty_ditolak` | DECIMAL(8,2) | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `RejectedQty` | Kuantitas barang yang ditolak/cacat. |
| `qty_masuk_stok` | DECIMAL(8,2) | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `StockedQty` (`ReceivedQty - RejectedQty`) | Kuantitas bersih barang yang masuk ke persediaan. |
| `harga_satuan` | DECIMAL(19,4) | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `UnitPrice` | Harga beli satuan barang dari vendor. |
| `total_harga_baris` | DECIMAL(19,4) | Metric / Measure | `Purchasing.PurchaseOrderDetail` | `LineTotal` | Total harga per item line (`OrderQty * UnitPrice`). |
| `subtotal_po` | DECIMAL(19,4) | Metric / Measure | `Purchasing.PurchaseOrderHeader` | `SubTotal` | Nilai subtotal keseluruhan pada header Purchase Order. |
| `pajak_po` | DECIMAL(19,4) | Metric / Measure | `Purchasing.PurchaseOrderHeader` | `TaxAmt` | Nilai pajak keseluruhan pada header Purchase Order. |
| `ongkir_po` | DECIMAL(19,4) | Metric / Measure | `Purchasing.PurchaseOrderHeader` | `Freight` | Nilai ongkos kirim keseluruhan pada header Purchase Order. |
| `total_tagihan_po` | DECIMAL(19,4) | Metric / Measure | `Purchasing.PurchaseOrderHeader` | `TotalDue` | Total tagihan akhir keseluruhan pada header Purchase Order. |

## 8. Daftar Tabel Staging (Implementasi Fisik DW V2)

Berikut adalah daftar 14 tabel *staging* (`stg_*`) pada database `dw_kelompok3` yang menampung hasil ekstraksi mentah dari database OLTP AdventureWorks sebelum ditransformasi ke 6 tabel dimensi dan 1 tabel fakta (`sql/ddl.sql`):

| No | Nama Tabel Staging | Tabel Sumber (AdventureWorks) | Tabel Target (DW Fisik) | Fungsi / Keterangan |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `stg_employee` | `HumanResources.Employee` | `dim_karyawan` | Menampung atribut kepegawaian (jabatan, jenis kelamin, tanggal rekrut) sebelum di-join dengan data person. |
| 2 | `stg_person` | `Person.Person` | `dim_karyawan` | Menampung nama lengkap karyawan (`FirstName`, `MiddleName`, `LastName`) untuk digabung dengan `stg_employee`. |
| 3 | `stg_product` | `Production.Product` | `dim_produk` | Menampung data master produk, kode produk, warna, dan harga jual standar. |
| 4 | `stg_productsubcategory` | `Production.ProductSubcategory` | `dim_produk` | Menampung data referensi subkategori produk untuk melengkapi hierarki produk. |
| 5 | `stg_productcategory` | `Production.ProductCategory` | `dim_produk` | Menampung data referensi kategori utama produk. |
| 6 | `stg_productcosthistory` | `Production.ProductCostHistory` | `dim_produk` | Menampung riwayat biaya standar produk untuk pelacakan perubahan harga/SCD Tipe 2. |
| 7 | `stg_vendor` | `Purchasing.Vendor` | `dim_vendor` | Menampung data pemasok/vendor, nomor akun, peringkat kredit, dan status aktif. |
| 8 | `stg_address` | `Person.Address` | `dim_geography` | Menampung data alamat dan kota untuk dimensi geografi. |
| 9 | `stg_stateprovince` | `Person.StateProvince` | `dim_geography` | Menampung kode dan nama provinsi/negara bagian. |
| 10 | `stg_countryregion` | `Person.CountryRegion` | `dim_geography` | Menampung kode dan nama negara/wilayah. |
| 11 | `stg_businessentityaddress` | `Person.BusinessEntityAddress` | `fact_purchasing` | Tabel penghubung antara `VendorID` (`BusinessEntityID`) dengan `AddressID` untuk lookup geografi. |
| 12 | `stg_shipmethod` | `Purchasing.ShipMethod` | `dim_ship_method` | Menampung master metode pengiriman, tarif dasar, dan tarif per unit. |
| 13 | `stg_purchaseorderheader` | `Purchasing.PurchaseOrderHeader` | `fact_purchasing` | Menampung data header transaksi pembelian (`PurchaseOrderID`, tanggal pesan, ID karyawan, ID vendor, ID metode kirim). |
| 14 | `stg_purchaseorderdetail` | `Purchasing.PurchaseOrderDetail` | `fact_purchasing` | Menampung rincian baris item pembelian (`PurchaseOrderDetailID`, `ProductID`, `OrderQty`, `UnitPrice`, `LineTotal`). |
